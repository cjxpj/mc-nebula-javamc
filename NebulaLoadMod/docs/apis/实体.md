### 生成生物

`$世界.生成生物 维度 类型 X Y Z$`

- 参数：
  - 维度 : `String`；注册名，如 `minecraft:overworld`
  - 类型 : `String`
  - X : `Integer`
  - Y : `Integer`
  - Z : `Integer`
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：`EntityType#create(ServerLevel)` + `moveTo` + `addFreshEntity`

示例：

```text
$世界.生成生物 minecraft:overworld minecraft:pig 0 64 0$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / 重编译 才生效。


### 刷怪蛋生成

`$世界.刷怪蛋生成 玩家 类型 [标记]$`

- 参数：
  - 玩家 : `String`；玩家名
  - 类型 : `String`；实体类型 id，如 `nebula_bridge:chest_creature`
  - 标记 : `String`（可选）—— 给定时要求手持物品 `custom_data.nebula_id` 等于它，否则直接返回 `0`（防误触）
- 返回值：`1` 生成成功（已扣 1 个）/ `0` 没生成（不扣）
- 返回值类型：`String`
- 实现：**原版 `SpawnEggItem#useOn` 的算法**——眼睛射线（`blockInteractionRange()`）→
  点到的方块没碰撞就原地生成、有碰撞就挪到点击面外侧、顶面再抬一格、点的是液体就地生成 →
  `EntityType#spawn(…, SPAWN_ITEM_USE, requireEmpty, invertY)`（居中 / 朝向 / 实体数据交给引擎）
- 失败回退：没看方块、类型不存在、领地禁止交互（`mayInteract`）都返回 `0`，不扣物品

示例：

```text
生:$世界.刷怪蛋生成 %人% nebula_bridge:chest_creature chest_mob_egg$
如果:%生%==1
    $世界.提示 %人% "§a放下一只箱子生物"$
如果尾
```

> 注意：这就是「原版刷怪蛋」和 `summon ~ ~ ~` 的区别——后者永远生成在**玩家脚下**，
> 而这里生成在你**点到的那个方块**上。看着空气右键什么都不发生，也不会扣蛋。

### 悬浮字

`$世界.悬浮字 维度 X Y Z 文本 [缩放] [上升] [时长]$`

- 参数：
  - 维度 : `String`；注册名，如 `minecraft:overworld`
  - X : `Float`
  - Y : `Float`
  - Z : `Float`
  - 文本 : `String`
  - 缩放 : `Float`（可选参数，省略时用宿主默认值）
  - 上升 : `Float`（可选参数，省略时用宿主默认值）
  - 时长 : `Integer`（可选参数，省略时用宿主默认值）
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 默认值：缩放 = 1，上升 = 1，时长 = 20（省略该尾部参数时）
- 失败回退：动作失败返回空串并记 WARN
- 实现：`Display.TextDisplay`：1.21.11 走 `EntityType.create(TagValueInput, Level, EntitySpawnReason.COMMAND)`（键名与 `/summon` 一致，setter 全是 private），宿主逐 tick `setPos` 上浮、到时 `discard`

示例：

```text
y2:[%y%+%身高%]
$世界.悬浮字 %维度% %x% %y2% %z% "§6§l暴击 §e12.5" 1.6 1.2 22$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / 重编译 才生效。

> 注意：文本里的 `§` 颜色码由宿主解析成组件样式（TextDisplay 走实体元数据，客户端不会自己认 `§`），含空格必须用双引号包住。`缩放` / `上升` / `时长` 省略或 <= 0 时用 1.0 / 1.0 / 20。实体是原版 `minecraft:text_display`，客户端零依赖；到时自动移除。实体带 `nebula_fx` 标签，宿主每秒扫一次残留（崩服 / 区块卸载留下的），不会永久留在世界里。

### 巡逻

`$世界.巡逻 实体 [半径] [追速] [闲速] [溜达]$`

- 参数：
  - 实体 : `String`；数字 id / UUID / 名称（必须是 `Container`，例如箱子生物）
  - 半径 : `Float`（可选参数，默认 12）—— 找掉落物的范围
  - 追速 : `Float`（可选参数，默认 1.2）—— 追掉落物时的移动速度倍率
  - 闲速 : `Float`（可选参数，默认 0.6）—— 没东西可捡时溜达的速度倍率
  - 溜达 : `Integer`（可选参数，默认 4）—— 「闲时挪一挪」的概率是 `1/溜达`
- 返回值：空串（**刻意不返回状态**——宿主会把返回值打进日志，每秒每只怪一条会把 `latest.log` 刷满；
  想知道「为什么没动」就用下面四个原语自己拼）
- 返回值类型：`String`
- 失败回退：实体不存在、或不是 `Container` 时什么都不做，同样返回空串
- 实现：`容器空位` → `附近掉落物` 按距离升序逐个 `可达`（第一个能走到的才是目标）→
  1.6 格内 `收取掉落物`、否则 `寻路` 追 → 一颗都够不着则 `1/溜达` 概率在 ±3 格内随机挪

示例：

```text
[事件]每秒
表:$世界.取实体列表 all 64 nebula_bridge:chest_creature$
遍历:i,怪=%表%
    $巡逻 %怪.uuid%$
结束

[函数]巡逻 怪
$世界.巡逻 %怪% 12 1.2 0.6 4$
返回
```

> 注意：这是**默认策略的封装**——一行就有完整行为，适合「容器生物自己捡东西」这种通用需求。
> 想要自己的策略就别调它，改用下面四个原语（`附近掉落物` / `可达` / `寻路` / `收取掉落物`）
> 自己拼；两条路互不影响。它不返回值，所以**不会**往日志里刷东西。

- 返回值：`1` 能走到 / `0` 走不到
- 返回值类型：`String`
- 失败回退：实体不存在返回 `0`
- 实现：`PathNavigation#createPath(…, 1).canReach()`

示例：

```text
行:$世界.可达 %怪% %x% %y% %z%$
```

> 注意：这是**预检**，不是保证——先 `可达` 再锁定目标，比"寻路失败再换"省一次 2 秒的卡顿。


### 寻路

`$世界.寻路 实体 X Y Z [速度]$`

- 参数：
  - 实体 : `String`；数字 id / UUID / 名称
  - X / Y / Z : `Float`
  - 速度 : `Float`（可选参数，默认 0.7）
- 返回值：`1` 已下单 / `0` 失败
- 返回值类型：`String`
- 实现：`PathNavigation#moveTo(x, y, z, speed)`

示例：

```text
$世界.寻路 %怪% %x% %y% %z%$
```

> 注意：原版没有「走到坐标」命令，所以只能出原语；下单后 AI 自己走，卡住由词库用
> `isStuck` 那套规则换目标（见 `nebula/箱子生物/main.n`）。


### 收取掉落物

`$世界.收取掉落物 实体 半径$`

- 参数：
  - 实体 : `String`；数字 id / UUID / 名称
  - 半径 : `Float`（可选参数，默认 1.6）
- 返回值：实际收进容器的件数
- 返回值类型：`String`
- 实现：半径内 `ItemEntity` 并入 `Container`，满了就留在原地

示例：

```text
收:$世界.收取掉落物 %怪% 1.6$
```

> 注意：先查 `容器空位` 再收，能避免"收了一半卡住"。

### 聚拢掉落物

`$世界.聚拢掉落物 维度 白名单 半径 [保护] [无限]$`

- 参数：
  - 维度 : `String`；注册名，如 `minecraft:overworld`
  - 白名单 : `String`；物品注册名的 JSON 数组，如 `["minecraft:cobblestone","minecraft:dirt"]`
  - 半径 : `Float`（可选参数，默认 2）
  - 保护 : `是|否`（可选参数，默认 `是`）；`是` 时带任意数据组件的物品不参与
  - 无限 : `是|否`（可选参数，默认 `是`）；`否` 时满堆留给原版合并
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 实现：`ServerLevel#getAllEntities` 快照 → 按总量降序贪心分组 → 小的 `setPos` 走向主堆、
  进 0.75 格并入宿主 `DropStack` 总量；**总量最大的那颗原地不动**

示例：

```text
$世界.聚拢掉落物 %维度% %物品表% %半径% %带组件% %无限%$
```

> 注意：这是**单向**的——只有小的会动。旧版让每颗都 `tp` 到最近邻，两个方向同时命中，
> 会看到已经堆好的大堆反过来去追新掉的小堆。另外 `白名单` 是实参里的 JSON，含 `[` `"` 也安全
> （实参在变量替换前就已切分好）。

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / 重编译 才生效。
