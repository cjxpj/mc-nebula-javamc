### 取方块

`$世界.取方块 维度 X Y Z$`

- 参数：
  - 维度 : `String`；注册名，如 `minecraft:overworld`
  - X : `Integer`
  - Y : `Integer`
  - Z : `Integer`
- 返回值：查询结果（可赋值给变量）
- 返回值类型：`String`
- 失败回退：查询失败返回空串
- 实现：`ServerLevel#getBlockState(BlockPos)` → `BuiltInRegistries.BLOCK.getKey`

示例：

```text
方块:$世界.取方块 minecraft:overworld 0 64 0$
```

> 注意：区块未加载时返回空，先 `$世界.区块已加载$` 判断或让管理员 `/forceload add`。

### 取相邻方块

`$世界.取相邻方块 方块数据 [预算]$ 或 $世界.取相邻方块 维度 X Y Z [预算]$`

- 参数：
  - 方块数据 : `String`
  - 维度 : `String`；注册名，如 `minecraft:overworld`
  - X : `Integer`
  - Y : `Integer`
  - Z : `Integer`
  - 预算 : `Integer`（可选参数，省略时用宿主默认值）
- 返回值：查询结果（可赋值给变量）
- 返回值类型：`String` / `Object`
- 失败回退：查询失败返回空串 / `{}` / `[]`
- 实现：26 邻域 `BlockPos.offset` + `getBlockState`，跳过空气，`ServerLevel#isLoaded` 防加载区块

示例：

```text
邻:$世界.取相邻方块 %方块% 64$
```

> 注意：两种调用形式二选一：传方块数据 JSON，或传 `维度 X Y Z` 坐标；`预算` 限制扫描格数。

### 设方块

`$世界.设方块 维度 X Y Z 方块名$`

- 参数：
  - 维度 : `String`；注册名，如 `minecraft:overworld`
  - X : `Integer`
  - Y : `Integer`
  - Z : `Integer`
  - 方块名 : `String`
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：原版 `setblock` 命令（Brigadier `parse + execute`），跨维度时加 `execute in <维度>` 前缀

示例：

```text
$世界.设方块 minecraft:overworld 0 64 0 minecraft:diamond_block$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / 重编译 才生效。

> 注意：动作延迟执行：同一词条里紧接着 `$世界.取方块$` 读到的仍是旧方块。


### 设方块状态

`$世界.设方块状态 维度 X Y Z 名称 [状态]$`

- 参数：
  - 维度 : `String`；注册名，如 `minecraft:overworld`
  - X : `Integer`
  - Y : `Integer`
  - Z : `Integer`
  - 名称 : `String`
  - 状态 : `String`（可选参数，省略时用宿主默认值）；`Text` 类型，吞掉该位次之后的全部实参并用空格拼接
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 默认值：状态 = 空（省略该尾部参数时）
- 失败回退：动作失败返回空串并记 WARN
- 实现：`BlockStateParser` 解析 `名称[属性=值]` 后 `setBlock`

示例：

```text
$世界.设方块状态 minecraft:overworld 0 64 0 minecraft:stone$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / 重编译 才生效。
