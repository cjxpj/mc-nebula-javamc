### 取玩家状态

`$世界.取玩家状态 玩家名 UUID$`

- 参数：
  - 玩家名 : `String`
  - UUID : `String`
- 返回值：查询结果（可赋值给变量）
- 返回值类型：`Object`
- 失败回退：查询失败返回空对象 `{}`
- 实现：`PlayerList#getPlayerByName` / `getPlayer(UUID)` 快照

示例：

```text
结果:$世界.取玩家状态 %玩家名% 示例文本$
```

### 传送玩家

`$世界.传送玩家 玩家 维度 X Y Z$`

- 参数：
  - 玩家 : `String`；传玩家名或玩家 JSON 对象（自动取 `名称`），不要传 UUID
  - 维度 : `String`；注册名，如 `minecraft:overworld`
  - X : `Integer`
  - Y : `Integer`
  - Z : `Integer`
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：`ServerPlayer#teleportTo(ServerLevel, x, y, z, yaw, pitch)`

示例：

```text
$世界.传送玩家 %玩家名% minecraft:overworld 0 64 0$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / 重编译 才生效。

### 设置Tab列表

`$世界.设置Tab列表 玩家 页眉 页脚$`

- 参数：
  - 玩家 : `String`；传玩家名或玩家 JSON 对象（自动取 `名称`），不要传 UUID
  - 页眉 : `String`；玩家列表（Tab）顶部文字，含空格时用双引号包住
  - 页脚 : `String`；玩家列表底部文字
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 换行：`|` 或字面量 `\n` 都会转成换行
- 颜色：`§` 颜色码由宿主解析，不依赖客户端
- 失败回退：动作失败返回空串并记 WARN
- 实现：`ServerPlayer#setTabListHeaderFooter(Component, Component)`

示例：

```text
$世界.设置Tab列表 %玩家名% "§b§l星云服务器|§7TPS {tps色}{tps}" "§7在线 §f{在线}"$
```

> 注意：页眉 / 页脚是**每个玩家单独一份**；要全服显示，用 `$世界.取玩家列表$` 遍历后逐个设置
> （参考 `server-1.21.11/nebula/Tab列表/main.n`）。

### 皮肤

`$世界.皮肤 操作 玩家 [参数]$`

- 参数：
  - 操作 : `String`；`正版`（参数=正版账号名）/ `文件`（参数=皮肤文件名）/ `链接`（参数=PNG 直链）/ `清除` / `刷新`；
    披风：`披风文件`（参数=披风文件名）/ `披风链接`（参数=PNG 直链）/ `披风清除`
  - 玩家 : `String`；传玩家名或玩家 JSON 对象（自动取 `名称`），不要传 UUID
  - 参数 : `Text`（可选，吞掉剩余实参）
- 返回值：空串（动作排队执行；结果异步落地）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN；异步失败会直接给玩家发一条 `§c[外观]` 提示
- 实现：`SkinService`——改 `GameProfile` 的 `textures` 属性后广播
  `ClientboundPlayerInfoRemovePacket` + `createPlayerInitializing`，让客户端重建 `PlayerInfo` 重新拉皮肤。
  `正版` 走 `api.mojang.com` + `sessionserver.mojang.com`（signed，原版客户端也认）；
  `文件`/`链接` 走内置 HTTP `/nebula/skins/`，textures 里的 URL 用占位域名 `nebula.invalid`，
  由装了本 mod 的客户端重写为当前服务器地址后下载。
- 皮肤与披风共用同一个 `textures` 属性里的 `SKIN` / `CAPE` 节点：改一半时另一半从当前 profile
  原样搬过来。`正版` 是整份替换（账号自带披风就一起换，没有就变成无披风）。

示例：

```text
$世界.皮肤 正版 %玩家名% Notch$
$世界.皮肤 链接 %玩家名% https://example.com/skin.png$
$世界.皮肤 披风文件 %玩家名% 示例披风.png$
$世界.皮肤 披风链接 %玩家名% https://example.com/cape.png$
$世界.皮肤 披风清除 %玩家名%$
$世界.皮肤 清除 %玩家名%$
```

> 注意：正版名只接受字母 / 数字 / 下划线（1-16 位）；皮肤 PNG 只认 64×64 / 64×32，
> 披风 PNG 只认 64×32。
> 自定义外观对**未安装本 mod 的客户端不可见**（原版只信任 `textures.minecraft.net`），
> 正版外观不受影响。玩家记录持久化在 `config/nebula-bridge/skins.json`，进服自动重放。


### 取皮肤

`$世界.取皮肤 玩家$`

- 参数：
  - 玩家 : `String`；传玩家名或玩家 JSON 对象（自动取 `名称`）
- 返回值：JSON 对象
- 返回值类型：`Object`
- 失败回退：玩家不在线返回 `{"玩家":名字,"类型":"无","来源":"","模型":"","有皮肤":"否","披风类型":"无","披风来源":"","有披风":"否"}`
- 实现：读 `SkinService` 的记录 + profile 里是否有 `textures` 属性

字段：

| 字段 | 说明 |
| --- | --- |
| `玩家` | 玩家名 |
| `类型` | `正版` / `文件` / `链接` / `无` |
| `来源` | 正版名 / 文件名 / 原始链接 |
| `模型` | `wide` / `slim` |
| `有皮肤` | `是` / `否`（profile 里当前是否有 textures） |
| `签名` | `是` = Mojang 签名（所有客户端可见）；`否` = 本地托管（需要装 mod） |
| `披风类型` | `正版` / `文件` / `链接` / `无` |
| `披风来源` | 正版名 / 文件名 / 原始链接 |
| `有披风` | `是` / `否`（textures 里当前是否有 `CAPE` 节点） |
| `更新` | 毫秒时间戳 |

示例：

```text
状:$世界.取皮肤 %玩家名%$
$世界.提示 %玩家名% "当前皮肤：%状.类型% %状.来源%"
$世界.提示 %玩家名% "当前披风：%状.披风类型% %状.披风来源%"
```
