# 伤害显示插件

RPG 风格的**悬浮字**飘血：玩家打怪时在目标头顶飘出伤害数字，暴击 / 击杀有独立样式；
目标回血时飘绿色 `+N`，**满血不飘**。

纯词库实现：Java 侧只把事件的原始字段（伤害、剩余血量、身高、是否暴击、回复量…）整理成变量，
样式、取整、开关全在 `main.n` 里；飘字本身走 `$世界.悬浮字$`（原版 `text_display` 实体，
客户端不用装 mod）。

## 配置

打开 `main.n`，改 `[f]初始化` 下的赋值行，然后执行（管理员）：

```
/nebula load 伤害显示
```

不用重启服务端。

| 变量 | 默认值 | 取值与含义 |
| --- | --- | --- |
| `伤害颜色` | `§c` | 普通伤害数字的颜色码 |
| `字号` | `1.0` | 普通飘字缩放（`1.0` ≈ 原版字号） |
| `暴击字号` | `1.6` | 暴击飘字缩放，越大越夸张 |
| `击杀字号` | `1.5` | 击杀那一下的缩放 |
| `上升` | `1.1` | 飘字上浮高度（格） |
| `时长` | `22` | 飘字存活 tick 数（20 tick ≈ 1 秒） |
| `小数位` | `1` | 伤害与回复保留几位小数，`0` = 只显示整数 |
| `显示暴击` | `是` | `否` = 暴击也用普通样式（字号仍是 `字号`） |
| `显示治疗` | `是` | `否` = 完全不显示回血 |
| `显示自然回复` | `否` | `是` = 饥饿值自然回血（每 0.5 秒 +1）也飘；默认关掉，避免刷屏 |
| `显示剩余` | `否` | `是` = 数字后面追加 `· 12.5`（目标剩余血量） |

## 显示效果

```
      暴击 7.5        ← 金色加粗，1.6 倍大小，起跳最快
        5.0           ← 普通伤害，红色
       +3.0           ← 治疗，绿色
```

- 普通伤害：`§c5.0`，字号 `1.0`
- 暴击：`§6§l暴击 §e§l7.5`，字号 `1.6`（暴击优先级最高，击杀的暴击按暴击样式走）
- 击杀：`§4§l7.0`，字号 `1.5`
- 治疗：`§a+3.0`，字号 `1.0`

数字是**结算后的真实值**：护甲、保护附魔、抗性、盾牌格挡都已经算完，不是武器面板值。

飘字出现在目标头顶（`%y% + %身高%`），约 1 秒内先快后慢上浮 `上升` 格后消失。

## 事件变量来源

### `[事件]实体受伤`

由 Java 侧在 `LivingDamageEvent.Post`（伤害已写入血量之后）转发，注入：

| 变量 | 内容 |
| --- | --- |
| `%攻击者%` | 攻击者玩家对象：`名称` / `uuid` / `类型` / `维度` / `x` `y` `z` / `血量` / `最大血量` |
| `%攻击者名%` | 攻击者名字，等价 `%攻击者.名称%` |
| `%实体%` | 被伤害的实体对象：`名称` / `id` / `类型` / `维度` / `x` `y` `z` / `血量` / `最大血量` |
| `%实体名%` | 目标名字，生物是它的显示名（僵尸 / 牛 / 玩家名） |
| `%伤害%` | 本次实际伤害（含暴击的 1.5 倍加成） |
| `%剩余%` | 伤害生效后目标的血量，死亡为 `0.0` |
| `%最大血量%` | 目标的最大血量 |
| `%身高%` | 目标碰撞箱高度（玩家 1.8 / 牛 1.4 / 蜘蛛 0.9），飘字定位用 |
| `%暴击%` | `是` / `否`，按原版 `Player#attack` 的落地暴击条件复算 |
| `%原因%` | 伤害类型 id，如 `player_attack` / `arrow` |
| `%致死%` | `是` / `否` |
| `%维度%` `%x%` `%y%` `%z%` | 目标所在位置 |

### `[事件]实体治疗`

由 Java 侧在 `LivingHealEvent`（血量写入**之前**）转发，注入：

| 变量 | 内容 |
| --- | --- |
| `%实体%` | 回血实体对象：`名称` / `id` / `类型` / `维度` / `x` `y` `z` / `血量` / `最大血量` |
| `%实体名%` | 实体名字 |
| `%数值%` | 本次**真实**回复量（已按最大血量截断） |
| `%之前%` / `%剩余%` | 回血前 / 回血后的血量 |
| `%最大血量%` | 最大血量 |
| `%身高%` | 碰撞箱高度 |
| `%原因%` | `自然回复` / `效果`（有再生效果）/ `其它` |
| `%满血%` | `是` / `否`，这次回复是否把血补满 |
| `%维度%` `%x%` `%y%` `%z%` | 实体所在位置 |

> **满血时宿主不转发这个事件**：`heal()` 被截断到 0 的回复直接丢弃，词库收不到，
> 所以不需要自己判「满血了要不要显示」。

## 开关与排查

```
/nebula list              # 看插件是否已加载
/nebula unload 伤害显示    # 关闭
/nebula load 伤害显示      # 重新开启
/nebula load 伤害显示    # 改完 main.n 生效
```

打了怪没反应时依次检查：`/nebula list` 里是否「已加载」、是否玩家打的（怪物互殴、摔落、岩浆不算）、
伤害是否真的大于 0（无敌帧内的重复攻击会被过滤）、`显示暴击` / `显示治疗` 是否被关掉。

没回血飘字时确认：目标是否已经满血（满血不转发）、`显示自然回复` 是否为 `否`（饥饿回血被过滤）。

## 已知限制

- **只有玩家造成的伤害会显示**：Java 侧在转发前就要求攻击者是玩家（弓箭、三叉戟的发射者也按玩家算），
  其它伤害源不进词库，避免无意义的开销。
- 玩家打自己（自伤）不显示。
- **暴击是复算的**：1.21.1 的伤害来源不带暴击标记，宿主按原版 `Player#attack` 的落地暴击条件
  （下落中、不在梯子 / 水里、不冲刺、没有失明）复算。横扫攻击误伤到的其它实体会跟着显示暴击，
  弓的满蓄力「暴击」不算在内（原版那是另一套判定）。
- 剩余血量是「扣完这次伤害」的值，不预判后续的持续伤害、摔落、队友补刀。
- 自然回血与生命恢复效果都走 `LivingEntity#heal`，原版没有「谁治的」信息，`%原因%` 只能按
  再生效果 + 玩家饥饿值粗分。
- 飘字是**服务端实体**：附近所有玩家都看得见，不是只给攻击者看。
- 每秒十来次以上的高频伤害会生成同样多的实体（每个存活约 1 秒）；连点器场景可以调小 `时长`。
- 飘字是真实实体，会随区块存盘；显示期间所在区块被卸载 / 服务端被强杀时，存档里可能留下飘字。宿主给它们打了 `nebula_fx` 标签并每秒扫一次，区块一加载就会被清掉，不会永久留在世界里。
- 颜色靠 `§` 代码，由宿主解析成组件样式；个别客户端装了去色插件时可能看不到颜色。
