# 皮肤文件放这里

把 PNG 直接丢进本目录，玩家用 `/皮肤 文件 <文件名>` 选它。

- 尺寸必须是 **64×64**（现代）或 **64×32**（旧版），其他尺寸会被拒绝。
- 文件名随意，只允许字母 / 数字 / `.` / `_` / `-`，扩展名必须是 `.png`。
- 不用重启：文件是每次请求现读的，换图后让玩家 `/皮肤 刷新` 即可。
- 链接方式（`/皮肤 链接 <直链>`）下载的图片会自动落到 `nebula/_skins/`，与本目录无关。

示例：

```
/皮肤 文件 我的皮肤.png
/皮肤 正版 Notch
/皮肤 查看
/皮肤 清除
```

> 自定义皮肤只对**装了星云客户端 mod** 的玩家可见（URL 不在 Mojang 的
> `textures.minecraft.net` 白名单里，原版客户端会忽略）。正版账号皮肤是
> Mojang 签名的，所有客户端都能看到。
