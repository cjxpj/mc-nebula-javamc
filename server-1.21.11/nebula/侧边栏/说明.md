# 侧边栏

右侧计分板信息板。三块内容：

```
      星 云 服 务 器          ← 标题（居中加粗，配置里改）
      在线 1                 ← 每秒刷新
      生物 239               ← 每 5 秒刷新
      ───────────
      CJXPJ: 0               ← 每个在线玩家一行，数字是背包里的泥土数
```

## 为什么金币是排行榜

原版侧边栏的显示槽位（`scoreboard objectives setdisplay sidebar`）是**全服共用一份**的
全局状态，不是每个玩家各一份。纯词库只能改命令层，做不到「每人看到自己的金币」。

所以金币走排行榜：每个在线玩家一行 `名字: 泥土数`，按泥土从多到少排序，
玩家自己那一行就在里面。这也顺带把「谁最有钱」变成公开信息。

如果确实想要「每人一份的侧边栏」，得改宿主（`NebulaLoadMod`）——给每个玩家单独发
`ClientboundSetDisplayObjectivePacket` + `ClientboundSetScorePacket`。用户已明确不做模组，
所以这里停在命令层。

## 布局怎么固定住的

三条信息行的**分数是固定排序键**（`2147482000` / `2147481000` / `2147480000`），
永远压在玩家金币行之上，所以数值怎么变行都不会跳。数字本身用
`scoreboard players display numberformat <行> nebula_board blank` 隐藏，
整行文字交给 `scoreboard players display name <行> nebula_board <组件>`。
1.21.11 里 `blank` 会让分数宽度归零，连「名字: 数字」中间的冒号间隔都不留。

玩家行不改这两个属性，分数就是金币数，所以按原版规则降序排出来天然是金币榜。

## 指令

| 指令 | 作用 |
| --- | --- |
| `/侧边栏` | 看状态（在线人数 + 用法） |
| `/侧边栏 数字` | 现算一遍：在线 / 生物 / 自己的金币，用来确认统计口径 |
| `/侧边栏 重载` | 立刻刷新（管理员） |
| `/侧边栏 关闭` | 收起侧边栏（管理员） |
| `/侧边栏 开启` | 重新展开 |

别名：`/sidebar`、`/sb`。

## 配置（`配置.json`）

```json
{
  "开关": "是",
  "标题": "§b§l星 云 服 务 器",
  "货币": "minecraft:dirt"
}
```

- `开关`：填 `否` 时整块停止刷新（侧边栏保留最后一帧）。
- `标题`：objective 的显示名，支持 `§` 颜色码。**不要用双引号**，会被当成组件语法结束。
- `货币`：计价物品的注册名，默认跟泥土商店一致（`minecraft:dirt`）。
  换算成别的货币就改这里，玩家行的数字自动跟着变。

改完用 `/侧边栏 重载` 或 `/nebula load 侧边栏` 生效。

## 统计口径

- **在线**：`$世界.取玩家数量$`，每秒。
- **生物**：`$世界.取实体列表$` 不带维度时一次扫全部维度，上限 **512** 条
  （实体特别多的服会截断，数字偏小）。判定方式是「有 `最大血量` 字段」= `LivingEntity`，
  再排掉 `minecraft:player`，剩下的都算生物（含盔甲架）。
  频率靠 `%服务器tick%` 的后两位 `00` 控制，约 5 秒一次。
- **金币**：`$世界.取物品数 <玩家> <货币>$`，每秒对每个在线玩家查一次背包。

## 已知取舍

- `[f]初始化` 每次都跑，`建板` 走的是 **`objectives remove` + `add`**：每次开服 / reload
  都把 objective 整个重建一遍，历史残留的玩家行（崩溃、事件漏收）一起清空。
  代价是 reload 瞬间侧边栏会空一下，下一秒补回来。第一次开服 `remove` 找不到 objective
  会留一条 WARN，之后不会。实测 `remove` 确实是清干净的唯一命令层手段
  （`scoreboard players list` 里的 holder 空壳会留着，但不影响显示）。
- 玩家退出靠 `[事件]PlayerEvent.PlayerLoggedOutEvent` 撤行。即使某次没收到，
  下次 reload / 开服重建也会清掉。
- 侧边栏最多显示 15 行。三条信息行占 3 行，剩下 12 行给玩家；超过 12 人在线时，
  金币最少的几位看不到自己那一行。
- **别用 `scoreboard players get <名字> nebula_board` 判断某行在不在**：目标没分数时
  这条命令会顺手创建一条 0 分记录，反而把行「造」出来。要查就看 `world/data/scoreboard.dat`。
