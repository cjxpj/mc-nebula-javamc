# 登录插件（聊天框按钮版）

账号密码登录。**密码不敲键盘**：进服后聊天栏里会出现一排可点击的按钮，点数字输入，点「确认」提交。

## 玩家看到的流程

1. 进服 → 被**传送到出生点**并切到**旁观模式**：不能攻击、破坏、放置、用物品、开箱子，怪物也不会索敌；
   同时挂上**失明 + 缓慢 + 隐身 + 无敌**（模式切换万一失败也有兜底），屏幕中央显示「星云登录」。
2. 聊天栏里出现三行按钮：

   ```text
   [星云] 设置密码
   点下面的数字输入密码，4-6 位
   [1] [2] [3] [4] [5]
   [6] [7] [8] [9] [0]
   [退格] [清空] [确认]
   ```

   点一下数字就等于输入一位，动作栏同一条显示「已输入 N 位 · 剩 M 秒」（不会和倒计时互相覆盖），点「确认」提交。
3. **首次进服**：输一遍 → 提示「第一步完成」→ 再输一遍相同的 → 两次一致就创建账号，立刻**传送回进服位置、恢复原游戏模式、清掉失明/缓慢**。
4. **已注册**：输一遍正确密码即放行；输错提示还剩几次，连续错 5 次踢出。
5. 300 秒没完成验证会被踢出。

未验证期间跑不掉：每秒检查一次坐标，离开出生点就被拉回来；旁观模式下攻击 / 破坏 / 放置 / 交互全被客户端禁掉；聊天会被吞掉并提示点按钮。

> **点太快会被原版踢**：Minecraft 对聊天/指令有「20 条 / 20 秒」的限流，点击按钮也算一条。
> 正常节奏输入（4-6 位 + 确认）不会触发；如果连续重试很多次，可能先被 `disconnect.spam` 踢下线。
> 所以 `最长` 默认是 6 位。

## 指令

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/登录`（`/login` `/l` `/登陆`） | 0 | 重发按钮面板（面板被刷上去、或 `/登录` 想重来时用） |
| `/重设 <在线玩家>` | 2 | 清掉对方账号，强制重新设置密码；对方会被踢下线 |
| `/nkey <数字\|退格\|清空\|确认>` | 0 | 面板按钮实际执行的指令，玩家不用手动敲 |

> 注意：`世界` 的指令名按正则匹配（`A|B|C` 会被当成正则的或），所以按钮指令用 `nkey`、
> 重置用 `重设`——不要起成「登录xx」或含 `l` 的名字，否则会被 `[指令]登录|login|l|登陆` 抢走。

## 目录结构

```text
nebula/登录/
├── main.n / 界面.n / 账号.n   ← 词库代码
├── 说明.md / nebula.ini
└── data/                      ← 运行数据（插件自己建，可整目录备份）
    ├── 账号.json
    ├── 会话.json
    └── 配置.json
```

## 数据文件

运行数据都在 `data/` 下，代码目录只有 `.n` 和说明。

| 文件 | 内容 |
| --- | --- |
| `data/账号.json` | `{UUID: {名, 密码, 注册, 上次, 次数, 失败}}`，密码是 `sha256(盐 + UUID + 密码)` 的十六进制 |
| `data/会话.json` | 未验证玩家的临时状态：`态 / 输入 / 暂 / 截止 / 模式 / 失败 / 已提示 / 原x,y,z,原维度 / 出x,y,z` |
| `data/配置.json` | 见下；`盐` 第一次运行自动生成，**改了它所有旧密码都会失效** |

```json
{
  "盐": "",
  "超时": 300,
  "最短": 4,
  "最长": 6,
  "失败上限": 5,
  "成功音": "minecraft:entity.player.levelup",
  "错误音": "minecraft:entity.villager.no",
  "点击音": "minecraft:ui.button.click",
  "提示音": "minecraft:block.note_block.pling"
}
```

## 边界情况

- **断线重连**：会话按连接重建（`[事件]玩家进入`），上一次「已登录」不会带到新连接，重连必须重新验证。
- **关服 / 重载**：`[f]初始化` 把所有「已登录」降级成「登录」，防止重启后直接进服绕过密码。
- **登录后回原位**：进服时把坐标（取整）和维度存进会话，验证通过后 `传送玩家` 回去并恢复原模式；
  原来就是冒险模式的（比如上一局被冻结时掉线）按生存处理。
- **两次输入不一致**：退回第一步重新设置，不写库。
- **长度不对**：小于 `最短` / 大于 `最长` 直接提示，不计失败次数。
- **跑出出生点**：每秒拉回一次；跳跃 / 走动都离不开。
- **旁观模式**：原版里唯一能保证「什么都做不了」的状态——攻击 / 破坏 / 放置 / 交互 / 用物品全部由客户端直接禁掉，
  不依赖我们拦事件；聊天和 `/nkey` 指令在旁观下照常可用，所以按钮面板不受影响。
- **无敌 + 隐身**：`设置无敌` 走 `abilities.invulnerable`（实测 `/damage` 返回 invulnerable），同时挂 `minecraft:invisibility` 效果 + `设置隐身` 标记，僵尸等怪物的 Brain 里不会出现 attack_target（实测召唤僵尸后 `Brain: {memories: {}}`）。
- **缓慢等级**：用 128 级（amplifier 127）；写 255 会溢出成 -2（负等级 = 加速），别改大。

## 依赖

- 宿主需要 `[事件]玩家进入`、`[事件]每秒` 和 `世界.点击消息`（本仓库 `NebulaMod` / `ClickChat` 已实现）。
- `世界.取复活点坐标` 取世界出生点；`世界.传送玩家` 做冻结与回位。
