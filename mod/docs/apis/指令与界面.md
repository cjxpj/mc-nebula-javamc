# 指令与界面 API

> 手写维护，无生成脚本。对应 LLSE 分组：GameAPI / Command / GuiAPI。
> 签名里 `[ ]` 是可选参数；参数格式、返回值类型与调试方式见 [`README.md`](README.md)。
> **查询立即返回、动作延迟执行**；查询失败返回空串 / `{}` / `[]` / `0`，动作失败记 WARN。

### 取物品数

`$世界.取物品数 玩家 物品$`

- 参数：
  - 玩家 : `String`；传玩家名或玩家 JSON 对象（自动取 `名称`），不要传 UUID
  - 物品 : `String`
- 返回值：查询结果（可赋值给变量）
- 返回值类型：`String` / `Object`
- 失败回退：查询失败返回空串 / `{}` / `[]`
- 实现：遍历 `Inventory#items / armor / offhand` 的 `ItemStack#getCount`，返回总数

示例：

```text
余:$世界.取物品数 %玩家名% minecraft:dirt$
$世界.提示 %玩家名% "§7余额：%余% 个泥土"
```


### 注册指令

`$世界.注册指令 规范名 [权限] 别名…$`

- 参数：
  - 规范名 : `String`
  - 权限 : `String`（可选参数，省略时用宿主默认值）
  - 别名… : `String`
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：`CommandDispatcher#register`；重复注册按插件 + 规范名幂等，权限变化拆旧节点重注册

示例：

```text
$世界.注册指令 商店 0 shop 泥土商店$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / reload 才生效。

> 注意：写在 `[f]初始化`（每次编译都跑，宿主去重）；`[f]卸载` 里要对应 `$世界.注销指令$`。改掉旧名字后旧入口要重启服务端才消失。

### 创建界面

`$世界.创建界面 玩家 [行数] 标题…$`

- 参数：
  - 玩家 : `String`；传玩家名或玩家 JSON 对象（自动取 `名称`），不要传 UUID
  - 行数 : `Integer`（可选参数，省略时用宿主默认值）
  - 标题… : `String`
- 返回值：界面对象 id（数字字符串）
- 返回值类型：`String`
- 失败回退：创建失败返回空串
- 实现：返回界面对象 id；同时发 `清空界面` 动作建好容器，Rust 侧记录归属插件 / 玩家 / 标题

示例：

```text
面:$世界.创建界面 %玩家名% 3 §a我的菜单$
```

> 注意：返回界面对象 id（数字字符串），后续 `界面物品` / `打开界面` / `关闭界面` 都要带这个 id。


### 界面物品

`$世界.界面物品 面 槽位 物品 数量 名称 说明 [发光]$`

- 参数：
  - 面 : `String`
  - 槽位 : `Integer`
  - 物品 : `String`
  - 数量 : `Integer`
  - 名称 : `String`
  - 说明 : `String`
  - 发光 : `String`（可选参数，省略时用宿主默认值）
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：校验对象归属后转成 `设界面物品` 动作（`ItemStack` + `CUSTOM_NAME / LORE / ENCHANTMENT_GLINT_OVERRIDE`）

示例：

```text
$世界.界面物品 %面% 0 minecraft:diamond 1 minecraft:stone 说明文字$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / reload 才生效。

### 打开界面

`$世界.打开界面 面 回调$`

- 参数：
  - 面 : `String`
  - 回调 : `String`
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`

示例：

```text

```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / reload 才生效。

> 注意：第二个参数是 `点击:[函数] … 结束` 定义的函数值，按值捕获局部变量；宿主点击时把 payload 作为闭包的 `%参数1%` 传入。
