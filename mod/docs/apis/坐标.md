# 坐标 API

> 手写维护，无生成脚本。对应 LLSE 分组：GameAPI / Basic。
> 签名里 `[ ]` 是可选参数；参数格式、返回值类型与调试方式见 [`README.md`](README.md)。
> **查询立即返回、动作延迟执行**；查询失败返回空串 / `{}` / `[]` / `0`，动作失败记 WARN。

## 本页方法

| 方法 | 类别 | 签名 |
| --- | --- | --- |
| [`取玩家坐标`](#取玩家坐标) | 查询 | `$世界.取玩家坐标 玩家$` |
| [`取复活点坐标`](#取复活点坐标) | 查询 | `$世界.取复活点坐标$` |
| [`设复活点`](#设复活点) | 动作 | `$世界.设复活点 X Y Z$` |

---

### 取玩家坐标

`$世界.取玩家坐标 玩家$`

- 参数：
  - 玩家 : `String`；传玩家名或玩家 JSON 对象（自动取 `名称`），不要传 UUID
- 返回值：查询结果（可赋值给变量）
- 返回值类型：`Object`
- 失败回退：查询失败返回空对象 `{}`
- 实现：`ServerPlayer#getX/getY/getZ`

示例：

```text
结果:$世界.取玩家坐标 %玩家名%$
```


### 取复活点坐标

`$世界.取复活点坐标$`

- 参数：无
- 返回值：查询结果（可赋值给变量）
- 返回值类型：`Object`
- 失败回退：查询失败返回空对象 `{}`
- 实现：`ServerLevel#getSharedSpawnPos()`

示例：

```text
结果:$世界.取复活点坐标$
```


### 设复活点

`$世界.设复活点 X Y Z$`

- 参数：
  - X : `Integer`
  - Y : `Integer`
  - Z : `Integer`
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：`ServerLevel#setDefaultSpawnPos(BlockPos, float)`

示例：

```text
$世界.设复活点 0 64 0$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / reload 才生效。
