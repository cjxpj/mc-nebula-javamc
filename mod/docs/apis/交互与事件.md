# 交互与事件 API

> 手写维护，无生成脚本。对应 LLSE 分组：GameAPI / Command / EventAPI。
> 签名里 `[ ]` 是可选参数；参数格式、返回值类型与调试方式见 [`README.md`](README.md)。
> **查询立即返回、动作延迟执行**；查询失败返回空串 / `{}` / `[]` / `0`，动作失败记 WARN。

### 提示

`$世界.提示 玩家 文本$`

- 参数：
  - 玩家 : `String`；传玩家名或玩家 JSON 对象（自动取 `名称`），不要传 UUID
  - 文本 : `String`
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：`ServerPlayer#sendSystemMessage(Component)`

示例：

```text
$世界.提示 %玩家名% 你好$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / reload 才生效。

> 注意：事件里的裸文本行会被广播，只想让某个玩家看到就用这个方法。


### 广播

`$世界.广播 文本$`

- 参数：
  - 文本 : `String`
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：`PlayerList#broadcastSystemMessage(Component, false)`

示例：

```text
$世界.广播 你好$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / reload 才生效。


### 执行命令

`$世界.执行命令 命令$`

- 参数：
  - 命令 : `String`
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：`MinecraftServer#getCommands().performPrefixedCommand(...)`

示例：

```text
$世界.执行命令 say 你好$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / reload 才生效。

> 注意：`say` 受 256 字符 chat 上限；宿主会吞掉命令回显，验证动作要用查询读回或原版 `execute if …` 反查。


### 取消事件

`$世界.取消事件$`

- 参数：无
- 返回值：查询结果（可赋值给变量）
- 返回值类型：`String` / `Object`
- 失败回退：查询失败返回空串 / `{}` / `[]`
- 实现：桥接层本次事件槽位 → `event.setCanceled(true)`

示例：

```text
结果:$世界.取消事件$
```

> 注意：只对「可取消」的事件有效；桥接层把标志写在本次事件槽位，宿主分发结束后统一 `setCanceled(true)`。
