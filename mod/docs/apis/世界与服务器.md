> 手写维护，无生成脚本。对应 LLSE 分组：GameAPI / Server。
> 签名里 `[ ]` 是可选参数；参数格式、返回值类型与调试方式见 [`README.md`](README.md)。

### 取时间

`$世界.取时间 [时刻]$`

- 参数：
  - 时刻 : `Integer`（可选参数，省略时用宿主默认值）
- 返回值：查询结果（可赋值给变量）
- 返回值类型：`Float`
- 失败回退：查询失败返回`0`
- 实现：`ServerLevel#getDayTime` / `setDayTime`

示例：

```text
结果:$世界.取时间$
```

`$世界.设时间 [时刻]$`
