### 生成生物

`$世界.生成生物 维度 类型 X Y Z$`

- 参数：
  - 维度 : `String`；注册名，如 `minecraft:overworld`
  - 类型 : `String`
  - X : `Integer`
  - Y : `Integer`
  - Z : `Integer`
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：`EntityType#create(ServerLevel)` + `moveTo` + `addFreshEntity`

示例：

```text
$世界.生成生物 minecraft:overworld minecraft:pig 0 64 0$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / reload 才生效。


### 生成实体

`$世界.生成实体 维度 类型 X Y Z [NBT]$`

- 参数：
  - 维度 : `String`；注册名，如 `minecraft:overworld`
  - 类型 : `String`
  - X : `Integer`
  - Y : `Integer`
  - Z : `Integer`
  - NBT : `String`（可选参数，省略时用宿主默认值）；`Text` 类型，吞掉该位次之后的全部实参并用空格拼接
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：`summon` 命令 + 可选 NBT（NBT 不含空格）

示例：

```text
$世界.生成实体 minecraft:overworld minecraft:pig 0 64 0$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / reload 才生效。

> 注意：原设计的整段 SNBT 改为 `维度 类型 X Y Z [NBT]`，NBT 不能含空格。

### 取实体列表

### 悬浮字

`$世界.悬浮字 维度 X Y Z 文本 [缩放] [上升] [时长]$`

- 参数：
  - 维度 : `String`；注册名，如 `minecraft:overworld`
  - X : `Float`
  - Y : `Float`
  - Z : `Float`
  - 文本 : `String`
  - 缩放 : `Float`（可选参数，省略时用宿主默认值）
  - 上升 : `Float`（可选参数，省略时用宿主默认值）
  - 时长 : `Integer`（可选参数，省略时用宿主默认值）
- 返回值：空串（动作排队执行）
- 返回值类型：`Null`
- 失败回退：动作失败返回空串并记 WARN
- 实现：`Display.TextDisplay`：`EntityType.create(CompoundTag, Level)`（键名与 `/summon` 一致，1.21.1 的 setter 全是 private），宿主逐 tick `setPos` 上浮、到时 `discard`

示例：

```text
y2:[%y%+%身高%]
$世界.悬浮字 %维度% %x% %y2% %z% "§6§l暴击 §e12.5" 1.6 1.2 22$
```

> 注意：动作**延迟执行**：同一词条里紧接着查询会读到旧值，要到下一次事件 / reload 才生效。

> 注意：文本里的 `§` 颜色码由宿主解析成组件样式（TextDisplay 走实体元数据，客户端不会自己认 `§`），含空格必须用双引号包住。`缩放` / `上升` / `时长` 省略或 <= 0 时用 1.0 / 1.0 / 20。实体是原版 `minecraft:text_display`，客户端零依赖；到时自动移除。实体带 `nebula_fx` 标签，宿主每秒扫一次残留（崩服 / 区块卸载留下的），不会永久留在世界里。
